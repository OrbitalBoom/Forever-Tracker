# Forever Tracker

A locally run companion site for a World of Warcraft character on **Forever** (Classic Era / vanilla, level cap 60, with room for the server’s extra content).

## How to open it

No server, no install, no internet required:

1. Open the `wow-forever` folder.
2. Double-click `index.html` (or open it in any modern browser).

Your character is saved automatically in this browser as you type — there is no Save button for that.

## Cloud save

To also keep a copy in this GitHub repository (so it comes back if the browser clears its storage, or if you open the site on another computer):

1. Click the **Cloud save** status in the header.
2. Create a [fine-grained personal access token](https://github.com/settings/personal-access-tokens/new). Name it something like “Forever Tracker”, and set a long expiration.
3. Under **Repository access**, choose **Only select repositories** and pick **Forever-Tracker**.
4. Under **Permissions**, set **Contents** to **Read and write**. Leave everything else as it is.
5. Generate the token, paste it into the Cloud save box, and click **Connect**.

After that, changes are written automatically (a few seconds after you edit, and when you leave the tab) to `save.json` on a dedicated `save-data` branch. That branch is never merged into `main`, so a save will not rebuild the site or clash with the weekly data refresh. The token stays in this browser only and is never written into `save.json` or an exported backup file.

A public copy of `save.json` can be read without a token, so a wiped browser can still restore your character. Connecting a token is only required to write updates. Because this repository is public, don’t put passwords or real-life personal information in your notes.

**Export JSON** / **Import JSON** are under Cloud save → Backup file, if you want a file on this computer.

## Tabs

- **Character** — name, race, class, spec, and level. Other tabs use this.
- **Goals** — Classic Era dungeons (Ragefire Chasm through Scholomance / Stratholme), raids through Naxxramas plus world bosses, notable mounts, and milestones. Add custom goals for Forever-specific content.
- **Gold** — gold log in g/s/c with a running total and chart, and a **Gold Farming** list of community camps and routes (mob grinds, instance resets, gathering, cloth, and Auction House flips) for your level, ranked by gold per hour (live auction prices when we can compute them, otherwise a dated source snapshot), with simple type pills and favorites that save with the rest of your character. Gathering farms use the professions and skills you entered on the Professions tab (the same saved list). Old links to this combined tab still open Gold; `#professions` opens the Professions tab.
- **Professions** — the professions you have and their skill (Classic cap 300), a crafting list with have/need materials, Auction House ROI, and the **Profession guide**. When you add professions and skill, the guide selects yours first, starts at your saved skill, marks earlier steps as done, highlights the current step, and shows what to craft next plus materials and estimated AH/vendor cost from here to the next milestone (75 / 150 / 225 / 300). Changing skill in the guide updates the saved profession skill (on change, not while you type). If no professions are listed, a short hint points you to the form above.
  - **Leveling guide 1–300** for Alchemy, Blacksmithing, Enchanting, Engineering, Leatherworking, Tailoring, Cooking, First Aid, and Mining (smelting). From your current skill it picks, for every skill point, the recipe with the lowest expected cost per point (orange 100%, then (grey − skill) / (grey − yellow) through yellow/green, 0 at grey), groups the points into steps with expected craft counts, and builds a shopping list (vendor vs AH), the bars/bolts/parts worth crafting yourself, and the recipes you must buy or find. Optimize for lowest gold cost (AH prices) or fewest raw materials; filter recipe sources (trainer, vendor, drop/quest, unknown); optionally subtract resale value. Step checkboxes save in the backup; **Lock this plan** freezes the steps so price changes don't reshuffle them. Recipes with a cooldown (transmutes, Mooncloth…) are never used for leveling. Recipe purchase prices are listed but not added to the step costs.
  - **Best profit by skill**: every recipe you can know at a chosen skill, with material cost, AH price (market and lowest), vendor sell price, profit per craft after the 5% AH cut, ROI %, units listed, and sold/day (when the source has it). Click any column to sort.
  - Works without prices (vendor prices and estimates, marked “est.”).
- **Notes & Journal** — dated adventure journal plus a searchable notes/guides pad.
- **Items & Upgrades** — a centered paper doll for equipped gear. Click a slot to see upgrades you can use at your level (class proficiency, required level, and score vs. what’s equipped), with a short “Coming soon” list for the next 3 levels. Hover any item (paper doll, upgrade list, item database, profession reagents, or gold-farm loot) for a Classic-style tooltip built from our item data — not Wowhead’s script. Hold Shift to compare with the item already in that slot. The item database (search, uses, drop/vendor/craft/quest sources, live US Normal Horde auction prices) sits below, collapsed. Custom items in your save still work.
- **Leveling Route** — hand-picked paths from level 1 to 60 for every race and both factions (default Undead Horde, following the Character tab when “Follow character race” is on). Pick a **route source** and a **variant**:
  - **Combined (default):** current public [RestedXP](https://github.com/RestedXP/RXPGuides) Forever Speedrun or Dungeon Guide through about 21 (Alliance) or 22 (Horde), then [OpenXP](https://github.com/mjared123/OpenXP)’s 21–60 community route. Each author’s order is kept. Combined also inserts optional **Forever Tracker add-on** chapters (auto-optimized, not RestedXP/OpenXP) for Riverglades (35–45, both factions), Shen’dralas (38–45, Horde plus a fuller Alliance path than OpenXP’s 40–41 stub), and Mount Hyjal (55–60, both factions). The **Include new zones** toggle is on by default; OpenXP chapters in those level bands are left in place and can be skipped with **Skip overlapping OpenXP chapters**.
  - **RestedXP free:** only the public Forever chapters (they end ~21–22; later RestedXP chapters are paid and are not included).
  - **OpenXP 1–60:** OpenXP’s own files, including its copies of the early RestedXP chapters (those copies lag the current RestedXP repo) plus OpenXP 21–60.
  - **Variants:** Speedrun, Dungeon Guide (RestedXP dungeon chapters 1–22, then OpenXP overworld; OpenXP’s standalone dungeon quest lists are shown separately). Mages also get **Mage AoE (RestedXP)** where those public files exist.

  Each step has a checkbox, skip, and notes. Progress is stored per character (name + race + source + variant) in the same localStorage backup. You can hide completed steps and jump to the current one. Coordinates come from the guide files (percentages, or world coordinates converted with Blizzard’s classic map bounds) and are labeled as such. No quest or coordinate is invented. The previous “every eligible quest” auto-route was replaced; old checkboxes are reset once so they don’t point at the wrong steps.
- **Talents** — WoW: Forever talent calculator (467 talents, build 1.60.1.70938). First point at 10, 51 at 60; milestone talents at 11 / 16 / 21 / 31 points. Dual Specialization at level 40 (Primary / Secondary). Published leveling builds load with one click and cite their guide and date. Once a build is loaded, a level bar lets you step from 10 to 60 (slider, ±1, and jumps to your level, +1/+2/+3/+5, or 60) without changing your character’s saved level. A callout names the talent gained at the viewed level, the next five levels appear as jump chips, and the tree highlights the new point (plus any upcoming points when you preview ahead). A **Classic Era (reference)** toggle shows the old 1.12 trees for comparison only.

### Known gaps (flagged, not reordered)

- Riverglades, Shen’dralas (Horde, and Alliance quests beyond OpenXP’s short 40–41 stub), and Mount Hyjal are not in the imported RestedXP or OpenXP routes. Combined adds optional Forever Tracker add-on chapters for them. Those chapters are auto-optimized from local catalog data (nearest-neighbor / hub batching on pickup coordinates), not author-written guides.
- forever-quests and ForeverDB have no records for these new zones. Prerequisites, exclusiveTo, and turn-in NPCs/coordinates now come from NorgannonDB where it lists them; the walking order waits on a prerequisite when both quests are in the same chapter. Zephras `data-also=chain` tags were too loose to treat as a prerequisite graph and were not used as chains.
- Quests whose giver stands outside the zone (for example breadcrumbs from Undercity or Stormwind) are listed first in their level band with the giver’s real zone and coordinates, and are left out of the in-zone walking optimization. Placeholder entries (“REUSE ME”) are dropped.
- Many catalog entries have no faction tag (especially Shen’dralas and Mount Hyjal) or no coordinates; those steps are marked **unverified** and listed at the end of the chapter as optional. NorgannonDB has no race restriction on them either, and the giver’s NPC reaction was not used to guess a side (it disagrees with Zephras’ tags too often).
- Objective coordinates are not shown — only pickup/giver points, turn-in points where NorgannonDB has them, and the published flight points (Rog'mar, Farholde Keep, Summit of Eternity, Tainted Foothills). Shen’dralas has no recorded flight point.
- Zephras Isle is covered in the Skyborne 1–9 and 9–13 / 9–12 RestedXP chapters.
- LevelForge 1–60 community chains were not imported: the LevelForge addon is MIT, but guide authors keep their rights and there is no clear redistribution license for bundling those routes here.

## Profession recipes and auction prices

**Recipes** (`js/professions-data.js`, rebuilt by `tools/professions/build_professions.py`):

- [LibProfessionDB](https://www.curseforge.com/wow/addons/libprofessiondb) by Pimptasty, **MIT License**, v1.10.1, Forever tree (client build 1.60.1.70938): recipes, reagents and counts, skill-up colours (orange/yellow/green/grey), required skill, recipe items, and recipe sources. Forever's own recipe vendors were recorded in game; trainer/drop sources for recipes shared with Classic are Vanilla's (from TrinityCore/AzerothCore world databases) and are marked “?” (not yet confirmed in Forever). Never-implemented recipes (AllTheThings list, MIT) are removed. 2,484 recipes: Alchemy 193, Blacksmithing 501, Enchanting 262, Engineering 274, Leatherworking 602, Tailoring 469, Cooking 133, First Aid 32, Mining 18.
- [wago.tools](https://wago.tools) DB2 exports of the live WoW: Forever client (`wowf` build 1.60.1.70959): item names and quality, vendor buy/sell prices, recipe yields (`SpellEffect`), skill-ups per craft, and cooldowns. Game data © Blizzard Entertainment.
- [CMaNGOS classic-db](https://github.com/cmangos/classic-db) (**GPL-3.0**), `npc_vendor`: which reagents vendors sell (Classic data; items new in Forever aren't covered and are priced from the AH).
- Names of 2 server-only items come from Forever Goblin's item list (from Blizzard's API).
- Server-side changes from [Blizzard's Forever hotfix notes](https://news.blizzard.com/en-us/article/24315281/wow-forever-hotfixes-november-17-2026) (bag cloth counts, Coarse Grinding Stone to 90, Tanning Rack at 125) were checked: the data already has them. From the Nov 17 notes, Orcish War Leggings is now listed as a quest reward (“The Old Ways”, replacement from Sumi).
- Known gaps: 168 recipes have no learn skill in the data (assumed at their yellow threshold, marked “*”); 211 have no source data at all (shown as “Trainer?”; turn off “Recipes with no source data” to hide them); recipes whose reagents don't exist in the Forever client (Season of Discovery leftovers) are hidden. Trainer rank gates (Journeyman at 50, Expert at 125, Artisan at 200) are Classic's rules.

**Auction prices** (`data/prices.json`, plus `data/prices.js` so the page also works from `file://`). The fetcher pulls the **full** US Normal Horde house dump (Blizzard: one request for auctions plus one for commodities; Forever Goblin: one `/api/m/us-114/prices` request) and keeps every priced auction — not a profession-only id list. Compact schema 2: each id maps to `[minBuyout, marketValue, quantity, soldPerDay?]`. The page also still reads the older schema 1 object shape. `marketValue` is the average of the cheapest 15% of units listed; `soldPerDay` is Forever Goblin only and is omitted when unknown. Copper per single item. House 114.

- **Official source:** Blizzard Battle.net Game Data API, `dynamic-forever-us` namespace: `/data/wow/ruleset/2/auctions/114` and `/data/wow/ruleset/2/auctions/114/commodities` (WoW: Forever uses rulesets instead of realms; ruleset 2 = Normal). Blizzard publishes a new snapshot about once an hour. Used under the [Blizzard Developer API Terms of Use](https://www.blizzard.com/en-us/legal/a2989b50-5f16-43b1-abec-2ae17cc09dd6/blizzard-developer-api-terms-of-use). Needs a free API client (see below).
- **Fallback while no API client is set up:** [Forever Goblin](https://forevergoblin.trade/about), a free fan site that stores the same hourly Blizzard API snapshots for every Forever auction house. Its robots.txt allows all crawling and it has no terms restricting reuse; the tracker makes one small request every 3 hours. The bundled snapshot in `data/prices.json` came from here (US Normal Horde, Nov 17, 2026 23:25 UTC). To turn the fallback off, add a repository variable `PRICE_FALLBACK` = `off`.
- **Auto-refresh:** `.github/workflows/prices.yml` runs every hour (every 3 hours on the fallback), runs `tools/prices/fetch_prices.py`, and force-pushes `prices.json`/`prices.js` as a single commit to the **`prices-data`** branch, so `main`'s history doesn't grow and Pages doesn't redeploy. The site loads `https://raw.githubusercontent.com/<owner>/<repo>/prices-data/prices.json` and uses whichever is newer: that file or the copy bundled in `main`. It also runs once when the workflow or the price script changes, and can be run by hand from the Actions tab (“Refresh auction prices” → Run workflow).
- **Set up the official API (optional, recommended):** sign in at <https://develop.battle.net/access/clients> with your Battle.net account → **Create Client** (any name, e.g. “Forever Tracker”; redirect URL can be left blank or `https://localhost`; tick “I do not have a service URL”; intended use: personal price tracker) → copy the **Client ID** and **Client Secret**. Then in GitHub: repo **Settings → Secrets and variables → Actions → New repository secret**: `BLIZZARD_CLIENT_ID` and `BLIZZARD_CLIENT_SECRET`. The next run uses Blizzard directly.
- Note: GitHub pauses scheduled workflows in a public repo after 60 days with no commits; the weekly data refresh keeps the repo active.

When doing the Wednesday refresh, also re-run `tools/items/build_items.py` (see `tools/items/README.md`) so the item database picks up new Forever client builds and NorgannonDB updates.

**Gold farming spots** (`js/gold-farms-data.js`): community camps and routes for WoW: Forever, with source URLs and dates on every entry. When doing the weekly refresh, re-check the principal sources listed in the file header (Conquest Capped, forevergold.dad, FrostyBoost, boosting.pro, Wowhead Forever profession overviews, ByteTavern, theforeverguides, botwowforever, Warcraft Tavern, warcraftmaps, r/wowforever), update sourced prices and dates, add or retire spots the community has confirmed or abandoned, and keep the exclusion list current. Prefer recent Forever posts over Classic-era guides. Tag each spot `forever` (priced or described for live Forever) or `classic` (Classic Era / beta, likely still applies — the UI labels it that way). Do not invent camps, drop rates, or gold-per-hour figures; only store numbers a source states, or let the UI compute a live value from `data/prices.js` / the `prices-data` branch. Leave out bug exploits, duplication, geometry glitches, and anything that violates Blizzard’s terms of use. Flag anything borderline as commonly hotfixed or nerfed, and leave it out if it is an actual exploit.

## Other data sources

- **Item database** (`data/items/`, built by `tools/items/build_items.py` — see `tools/items/README.md` for the Wednesday refresh). Forever-confirmed facts come from the live client via [wago.tools](https://wago.tools) DB2 `ItemSparse`/`Item` (name, quality, item level, required level, slot, vendor buy/sell, icon file id) and from [zmarotrix/NorgannonDB](https://github.com/zmarotrix/NorgannonDB) (GPL-3.0; drops with chances, vendors, quest uses and rewards, recipes), merged with this repo's Forever profession data (LibProfessionDB). Numeric gear stats and weapon damage are Classic-reference, from the public [Napalmsteak/WoW-Classic-Item-Caches](https://github.com/Napalmsteak/WoW-Classic-Item-Caches) Wowhead Classic tooltips and from [cmangos/classic-db](https://github.com/cmangos/classic-db) `item_template` (GPL-3.0), because the Forever client stores stat *allocation weights*, not raw amounts — those amounts are labelled in the UI and may differ if Forever changed a piece. Items that appear only in Classic sources (no `ItemSparse` row in the live client) are marked Classic-reference and are omitted from the upgrade finder. Auction prices come from the existing `prices-data` feed, not from this build. Do not invent stats, drop rates, or prices.
